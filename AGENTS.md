# Project

Astro static site starter with a reusable design system.

For Astro API or configuration changes, consult the [official Astro docs](https://docs.astro.build/)
for the major version declared in package.json.

## UI changes

Before changing components, layouts, or styles, read
[UI conventions](docs/coding-standards.md).

When changing a public component API, update its documentation
under docs/components/.

## Verification

For application source or build configuration changes, run
`npm run build`.

The current build does not perform full TypeScript checking.
No automated test runner or lint script is configured.
Report the checks performed and any validation gaps.
